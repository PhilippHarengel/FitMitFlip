# Cookbook photo prompts

First four dishes from the production cookbook. The worker action `rezepte` sorts the Notion recipe book with German name order (`localeCompare` de). In that order these are the first four recipes in `essen-einkauf-wochenplan/recipes/rezeptbuch.yaml`. The same four led the grid in the simulator.

Shared look, repeated in every prompt so each one can be used alone:

- Square frame.
- Realistic food photograph, one set: natural color, no heavy filter, no plastic studio shine.
- Camera about 30 degrees above the subject, slight three-quarter angle, 50mm look, shallow depth of field.
- Soft late-morning window light from the left, gentle shadow to the right.
- Pale oak table, off-white wall, one plain linen napkin. No extra props, no text, no logo, no hands, no people.
